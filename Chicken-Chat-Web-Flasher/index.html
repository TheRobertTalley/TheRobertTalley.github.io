02

Network setup

Install first, close the installer, then connect here. Settings go directly to your board.

Start with the gateway. Create and keep one private network file. Load that same file when setting up every repeater or controller.

Use the same fixed 2.4 GHz channel on the farm router and all boards. Existing feeder and shaker boards use channel 6.

The network file contains private keys. Keep it with your farm records. It stays on your computer and is never uploaded to this website.

04

Flash procedure

Three steps. Keep the USB cable connected until the install is complete.

  1. 1
    Pick the controller

    Select Connect on the matching card, then Install.

  2. 2
    Choose the serial port

    Allow browser access to the connected ESP32.

  3. 3
    Let it finish

    Do not unplug or close the page during the flash.

Keep existing settings: Leave the erase option unchecked when updating the same board profile. Erasing clears saved controller and network settings.
